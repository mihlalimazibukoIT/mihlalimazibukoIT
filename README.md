Support Philosophy

Reset. Reboot. Resolve. Repeat. — but never skip the thinking:

Listen first — the user's description is evidence, not noise
Diagnose by layer — device → OS → network → account → application
Document everything — a fix nobody can find is a fix nobody has
Follow up — a ticket is closed when the person is working, not when the tool says so
Automate the repeat — if I fix it twice, I script it or dashboard it
